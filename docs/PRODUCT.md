# PRODUCT.md

## 产品目标

单文件交互式 3D 海边灯塔夜景 demo：深夜海边，红白条纹灯塔立于礁石之上，体积光束旋转扫射海面，涌浪起伏。用于展示与观赏。

## 功能列表
<!-- 全部功能，每项附验收标准 -->

### F1 场景构成
红白相间条纹的低多边形灯塔（含灯室）立于礁石底座上，礁石坐落在深夜海面中。
**验收标准**
- 灯塔为红白相间条纹的低多边形造型，含灯室结构
- 礁石底座由多块低多边形岩石组成，位于海面之上并承托灯塔
- 双击打开 HTML（联网状态）即可看到完整场景，无需构建步骤或本地 server

### F2 深夜氛围
深蓝渐变夜空 + 星空 + 月亮 + 场景雾 + 低多边形云；页面左下角一行操作提示。
**验收标准**
- 天空为深蓝系渐变，可见随机分布的星星与月亮
- 场景有雾效，远处海天相接处呈朦胧过渡
- 可见漂浮的低多边形云
- 页面左下角显示一行拖拽/缩放操作提示

### F3 体积光束
灯室发出伪体积光束（半透明锥体 + 加色混合 + 灯室光晕），持续旋转扫射海面。
**验收标准**
- 光束呈半透明锥体，加色混合有光感，透过光束仍可见其后景（星星/月亮）
- 光束绕灯室竖轴持续旋转扫射
- 灯室处有可见光晕

### F4 起伏海面
自定义 shader 波浪，明显起伏的涌浪。
**验收标准**
- 海面有肉眼清晰可见的涌浪起伏，波形平滑连续
- 浪沿可没过礁石边缘再退去
- 海面无外部贴图依赖（纯代码生成）

### F5 视角交互
鼠标拖拽旋转视角 + 滚轮缩放，带阻尼与俯仰角限制；触屏顺带支持。
**验收标准**
- 按住拖拽可环绕场景旋转视角，松手后带阻尼缓停
- 滚轮可缩放远近，存在合理远近限位
- 俯仰角受限，视角不会钻到海面以下
- 触屏设备上单指旋转、双指缩放可用

### F6 加载失败兜底
CDN 加载失败（断网或 CDN 不可达）时显示友好提示而非白屏。
**验收标准**
- 断网状态下打开页面，显示明确提示（如「需要联网加载 Three.js」），而非白屏

## 不做什么
<!-- 明确不在本期范围的功能或方向，防止 AI 扩大范围 -->
- 写实风格（坚持 low-poly 风格化）
- 真体积光 raymarching
- 风暴浪、白沫粒子
- 海鸥、小船/浮标（MVP 后可追加项）
- 音效（海浪声、雾笛等）
- 昼夜循环、白天场景
- 点击彩蛋交互（开关灯、切昼夜、涟漪等）
- 移动端专项性能优化（触屏支持但不承诺帧率）
- 本地 server 部署需求（必须双击即开）
