# Lighthouse Night · 海边灯塔夜景

单文件交互式 3D 海边灯塔场景：深夜海边，红白条纹灯塔立于礁石之上，体积光束旋转扫射，涌浪起伏；四态天气（晴夜 / 多云 / 雨夜 / 暴雨闪电）与绕塔盘旋的海鸥。基于 Three.js，全部代码内联于一个 HTML 文件，双击即玩。

## 快速开始

1. 双击打开 `index.html`（需联网，Three.js 从 CDN 加载）
2. `C` 切换天气 · 鼠标拖拽旋转视角 · 滚轮缩放；触屏单指旋转、双指缩放

需求与验收标准见 `docs/PRODUCT.md`，技术方案见 `docs/ARCHITECTURE.md`。

仓库：https://github.com/NanoBei/lighthouse-night
